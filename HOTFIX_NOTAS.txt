V25H4.7 HOTFIX 1 — ARRANQUE

CAUSA EXACTA
En app-main.js quedó esta secuencia:
  let adminPredictionSummaryPollaId = null; adminPredictionSummaryAt = 0;
  let adminPredictionSummaryAt = 0;

La primera asignación intenta usar adminPredictionSummaryAt antes de que su `let`
haya sido inicializado (Temporal Dead Zone). Eso genera un ReferenceError al
ejecutar app-main.js y detiene TODO el JavaScript principal. Por eso la app
mostraba la estructura visual pero no cargaba ningún dato ni interacción.

CORRECCIÓN
Ahora es:
  let adminPredictionSummaryPollaId = null;
  let adminPredictionSummaryAt = 0;

NO CAMBIA
- SQL
- Backend
- DB
- lógica de negocio
- versión pública V25H4.7

SUBIR SOLO
1) app-main.js
2) index.html
3) sw.js

Después cerrar completamente la PWA y abrirla otra vez, o aceptar la actualización.

VALIDACIÓN
- node --check app-main.js: OK
- node --check sw.js: OK
- fallo TDZ eliminado
